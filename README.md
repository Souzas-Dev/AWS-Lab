# AWS Lab

Repositório dedicado aos meus laboratórios práticos em Amazon Web Services (AWS).

O objetivo deste projeto é registrar minha evolução em computação em nuvem por meio de atividades práticas, documentação técnica, scripts, evidências e aprendizados obtidos durante cada laboratório.

## Laboratórios

| Serviço | Descrição | Status |
| --- | --- | --- |
| Amazon EC2 | Provisionamento, segurança, monitoramento, armazenamento e automação | Em andamento |

## Estrutura

Cada serviço AWS possui sua própria pasta com documentação, scripts e evidências da execução.

```text
AWS-Lab/
└── EC2/
    ├── README.md
    ├── docs/
    ├── evidencias/
    └── scripts/
```

## Objetivos

- Consolidar conhecimentos práticos em AWS.
- Documentar configurações e decisões técnicas.
- Registrar evidências das atividades realizadas.
- Desenvolver boas práticas de infraestrutura em nuvem.
- Construir um portfólio técnico de laboratórios AWS.

## Ambiente

Os laboratórios podem ser executados em ambientes educacionais temporários disponibilizados durante os cursos e treinamentos realizados.
